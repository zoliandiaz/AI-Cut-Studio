# AI Cut Studio · 免费内测

独立的 AI 视频粗剪工具：把一组素材整理为可审核、有故事段落的初剪，支持 FCPXML 工程导出，供后续编辑。

这是 macOS Apple Silicon 的原生桌面应用。本仓库提供内测安装包、使用说明和问题反馈，**目前不公开 AI Cut Studio 自有源码**。安装包附带的第三方源码与许可仍按各自许可证提供。

## 下载与安装

在本仓库 **Releases** 中选择标记为 **Pre-release** 的 `v0.3.2-beta.1`，下载 `AI-Cut-Studio-0.3.2-beta.1-AppleSilicon.dmg`。约1GB，视频工具和两套语音模型已包含，不需要另装 Homebrew、Xcode 或下载模型。

打开DMG，把App拖入“应用程序”，完成后推出镜像，再打开App。详细步骤见[安装说明](INSTALL.md)。

**本版未完成 Apple Developer ID 签名和公证。** macOS可能阻止首次打开；请自行查看“隐私与安全性”的系统提示，不要关闭系统安全保护。若仍无法打开，请反馈完整提示。

## 可以做什么

- 新建、切换本地项目；视频只引用原文件，不复制整套素材。
- 设置内容类型、风格、目标时长及浮动范围，填写剪辑要求。
- 本地视频信息读取、轻量代理、全片画面覆盖索引及带时间码语音转录。
- 使用用户自己的 DeepSeek API Key 做画面观察、故事章节与选段；审核和调整剪辑清单。
- 粗剪预览、FCPXML工程导出；可选择包含字幕或不含字幕，并选择保存位置。
- 初剪后生成字幕；外语原文与中文翻译分开导出，供后续编辑。识别异常会提示复核，也可明确选择导出未校验字幕。
- 项目持久化、阶段结果复用、任务续跑与生成缓存清理。

自动配乐、音乐卡点、转场、调色和精修不在本版范围内。

## 免费的范围与联网

**App内测使用免费；DeepSeek API不是由本项目免费提供。** 用户自行配置Key并承担其账户产生的服务费用。本版没有免费额度承诺或自动费用上限承诺。

元数据、代理和语音识别在本机处理。启动AI分析/编排/翻译后，会向DeepSeek发送相关的低清抽帧、转录、剪辑要求及编排所需信息；**原始视频文件不上传，不代表内容完全不离开电脑**。请先阅读[数据与隐私说明](PRIVACY.md)。

## 兼容性与内测状态

支持目标：Apple Silicon、macOS14及以上；不提供Intel或Windows版。开发验证在M5/macOS26完成；M1 16GB和macOS14尚未实机验证，M2 Pro32GB的独立安装也尚未完成实机验收。不能据此保证所有设备表现。

FCPXML导出曾在剪映专业版11.7验证特定工程及双轨字幕小样的导入；这是有限范围的兼容性实测，不保证其他工程或版本均可用。

AI Cut Studio为独立开发项目，与剪映及其运营方不存在隶属、合作或授权关系。提及第三方产品名称仅用于说明实测兼容性，相关名称和商标归各自权利人所有。AI故事质量、精彩动作保留和中外语混说字幕仍需人工检查。详见[已知限制](KNOWN_ISSUES.md)。
