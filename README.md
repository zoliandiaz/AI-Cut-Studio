# AI Cut Studio · 先把故事剪出来

**把一堆拍摄素材，整理成一条有故事线、可以继续修改的初剪。**

拍完一次活动、旅行或日常记录，你可能有很多段视频：有口播，有现场互动，也有值得保留的拍摄过程。真正费时间的，往往是先看完素材，再判断哪些值得留、该怎样排列，才能把事情讲清楚。

AI Cut Studio是一款独立的Mac AI视频粗剪工具，帮助你完成这一步。你告诉它想剪成什么类型、大约多长、希望保留什么，它会结合画面观察与语音内容，提出故事章节和选段，生成供你审核的剪辑时间线。你可以预览、调整，再导出工程进入后续精修。

## 本次更新为什么增加原片对照轴

初剪拼好以后，精修时常需要找回某个片段前后发生的事。只看成片时间线不容易定位，因此0.3.3增加了完整原片对照导出：保留全套素材和原声，在已用区间边界切开，标上初剪编号，并附时间码定位表。这样可以补镜头、调整切点，也不会把未选中的内容误当成不可用。

剪映11.7小样中，两条时间轴导入为两个独立草稿；编号标记轨可见，预设红字颜色未保留，原视频块不会自动染红。完整项目已完成导出和结构校验，其他工程及版本仍需实际验证。

## 适合什么情况

- **活动Vlog：** 从准备、拍摄过程、人物互动到结束回顾，尝试整理出有前后关系的内容。
- **同时有画面和口播的记录：** 既考虑说了什么，也把现场过程和画面纳入选段依据，不只按逐字稿删句子。
- **素材较多、已有大致方向：** 想先得到一版可修改的结构，减少从空白时间线开始梳理的工作。

本轮故事流程主要围绕活动Vlog验证；旅行、日常或其他题材的效果仍需用实际素材测试。AI可能漏掉精彩镜头，也可能误判语境，选段和故事关系仍由你审核。

## 一次使用会经历什么

**导入素材 → 写下目标 → 生成故事初剪 → 预览和调整 → 导出工程精修**

1. **建一个项目，导入视频。** 原视频留在原处，App生成轻量代理和分析结果，避免反复复制整套大文件。
2. **说明你想要的内容。** 例如：“剪成约15分钟的摄影活动Vlog，允许前后浮动2分钟，保留有趣互动和精彩拍摄过程，讲清楚整个活动。”目标时长、类型和自由要求都可以设置。
3. **让App整理素材和结构。** 本机转录语音，AI结合低清画面观察和转录，尝试安排故事章节、选段和顺序。已有阶段结果会尽量复用。
4. **看第一版，再做决定。** 在粗剪预览和审核清单中检查选段、顺序、段落与时长，调整不合适的内容。生成结果是编辑建议，需要你看片判断。
5. **导出可继续编辑的工程。** 选择保存位置，导出FCPXML；也可以在初剪后生成字幕，再选择带字幕或不带字幕导出。最后在兼容的编辑软件里继续精修。

上面的15分钟是剪辑要求示例，不是每组素材都能自动达到的效果承诺。

## 最后得到什么

- 一份可审核、可调整的初剪清单，以及故事章节和选段理由。
- 一段用于检查故事与节奏的粗剪预览。
- 一个FCPXML工程文件，保留继续编辑的空间。
- 可选的字幕：中文内容配中文，外语内容保留原文并另附中文翻译；可导出独立SRT。识别与翻译都可能出错。

本版专注于**素材梳理和故事初剪**。配乐、音乐卡点、转场、调色和最终精修仍在后续编辑软件中完成。它目前也不是只丢入素材、无需审核就能直接发布成片的工具。
